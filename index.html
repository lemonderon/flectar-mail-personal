Flectar Mail Personal

A personal Google OAuth registration for using a locally installed copy of Flectar Mail with the operator’s own email accounts.

This registration is maintained by GitHub user lemonderon. It is separate from the upstream Flectar project and is not its official website or a public hosted email service.

What the registration enables

Flectar Mail is an email client. Google authorization lets the installed application identify the account and read, compose, send, organize, and permanently delete Gmail messages as directed by the user.

The requested scopes are openid, email and profile information, and https://mail.google.com/. The full Gmail scope includes permanent deletion, so authorize only software you trust.

Where the application runs

The email client runs on the user’s device. This static website explains the OAuth registration and its privacy policy; it has no Google sign-in form, mail API backend, or access to mailbox contents or OAuth tokens.

Publishing an OAuth registration does not mean Google has verified it or that an alpha release of the application is stable.

Contact

Questions about this personal registration: contact the operator through the repository issue tracker. Do not post private information in public issues. Software documentation and issue reports belong to the upstream Flectar Mail project.
